# BHUSAMANVAY website

No install needed.

**VS Code / Antigravity:** open this folder, then either
- install the "Live Server" extension, right-click `index.html` → Open with Live Server, or
- run `python -m http.server 5500` in the terminal and open http://localhost:5500

You can also double-click `index.html`.

Files: `index.html` (page), `style.css`, `script.js` (all content and interactions), `assets/` (prototype screenshots).
Fonts load from Google Fonts when online; a fallback font is used offline.
